# Генератор LLVM IR на C

Программа строит LLVM IR для «Колонии турмитов» и выполняет его через
интерпретатор ExecutionEngine. 32 турмита движутся по замкнутому полю
и оставляют шестицветные следы. Графика выводится через SDL2.

Для сборки нужны C-компилятор, GNU Make, `pkg-config`, SDL2 и LLVM
с заголовками и поддержкой libffi. Проверено на LLVM 22.1.8.

```sh
make
make run
```

Дополнительные команды:

```sh
./build/irgen --frames 100           # выполнить 100 кадров
./build/irgen --headless --frames 16 # запуск без окна
make ir                            # сохранить IR в build/app.ll
```
